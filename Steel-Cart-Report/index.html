The "stale total" observed originally is correct behavior: the invalid submission was blocked, so nothing should have changed.

from Magento core (`Magento\SalesRule\Model\Coupon\Massgenerator` /

`app/i18n/id_ID.csv` (or store-view translation) entry exists for the
exact English phrase 'You used coupon code "%1".'.

Add a translation entry to the Indonesian language pack, e.g. in
`app/i18n/id_ID.csv`:
`"You used coupon code \"%1\".","Anda menggunakan kode voucher \"%1\"."`
then flush the translation cache (`bin/magento cache:flush` /
`translation`).
